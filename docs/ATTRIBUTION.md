# Attribution

Required notices for every source this catalog draws on, reproduced **verbatim** where the
licence requires it.

This file is the human-readable copy. The same notices are emitted into the `attribution`
block of every published bundle, so a consumer of the JSON never has to come back here to
discharge an attribution obligation. `tools/build.mjs` derives that block from the source
kinds actually present in the data, so a notice can never drift out of sync with what
shipped — and a notice for a source no longer used disappears on its own.

---

## openFDA / DailyMed Structured Product Labeling

- **Licence:** CC0 1.0 / U.S. public domain
- **URL:** <https://open.fda.gov/license/>
- **Retrieved:** 2026-08-23
- **Evidence id namespace:** `openfda:<SPL set id>`

openFDA's licence page states:

> openFDA is a beta research project and not for clinical use. The data may not yet be
> validated. The openFDA API is provided "as is" and without any warranty.

The disclaimer returned with every API response, which travels with the data:

> Do not rely on openFDA to make decisions regarding medical care. While we make every
> effort to ensure that data is accurate, you should assume all results are unvalidated.

Data published by the U.S. Food and Drug Administration is a work of the United States
Government and is in the public domain. openFDA imposes no attribution requirement; this
notice is carried anyway so the provenance of every label-derived value stays visible.

**What was taken:** the SPL `set_id` of the current label for each approved compound, and
the factual content of that label's indications, warnings and monitoring instructions —
restated in our own words. No label text is reproduced.

## UniTox

- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **URL:** <https://doi.org/10.5281/zenodo.14042913>
- **Retrieved:** 2026-08-23
- **Evidence id namespace:** `unitox:<exact Generic Name row>`

**Required attribution:**

> UniTox: Leveraging LLMs to Curate a Unified Dataset of Drug-Induced Toxicity from FDA
> Labels. Jake Silberg, Elana Simon, Kyle Swanson and James Zou, Stanford University.
> Published on Zenodo, DOI 10.5281/zenodo.14042913. Licensed under the Creative Commons
> Attribution 4.0 International License (<https://creativecommons.org/licenses/by/4.0/>).

The CC BY 4.0 deed states:

> You are free to share — copy and redistribute the material in any medium or format — and
> adapt — remix, transform, and build upon the material for any purpose, even commercially,
> under the following terms: Attribution — You must give appropriate credit, provide a link
> to the license, and indicate if changes were made.

**Indication of changes:** UniTox ternary ratings are *cited*, never restated. Each source
row records the exact UniTox `Generic Name` it came from and its ratings across all eight
axes, verbatim. No UniTox reasoning text is reproduced. Where a UniTox row was consulted
but its rating did not support a claim, the row is still recorded with a note saying so
rather than being silently dropped.

**Material caveat, stated because honesty requires it:** UniTox ratings were generated by
GPT-4o from FDA label text. They are a machine reading of a label, not an independent
clinical finding, and this catalog treats them as corroborating evidence for a claim
sourced elsewhere — never as the sole basis for one.

**What was taken:** the eight per-drug organ-toxicity ternary ratings (cardiotoxicity,
dermatological, hematological, infertility, liver, ototoxicity, pulmonary, renal) for the
2,418 drugs in the dataset, used to corroborate `burdens` relations.

## DILIrank 2.0

- **Licence:** U.S. public domain (work of the United States Government)
- **URL:** <https://www.fda.gov/science-research/liver-toxicity-knowledge-base-ltkb/drug-induced-liver-injury-rank-dilirank-20-dataset>
- **Retrieved:** 2026-08-23
- **Evidence id namespace:** `dilirank:<LTKBID>`

> DILIrank consists of FDA-approved drugs annotated for their potential to cause
> drug-induced liver injury (DILI), developed by the FDA's National Center for
> Toxicological Research. DILIrank 2.0 comprises 1,336 drugs assigned to four classes:
> vMost-DILI-concern, vLess-DILI-concern, vNo-DILI-concern and Ambiguous-DILI-concern.

Produced by the U.S. Food and Drug Administration. As a work of the United States
Government it is in the public domain and carries no attribution requirement; this notice
is carried anyway.

**What was taken:** the LTKB identifier, compound name, severity class and DILI-concern
class for each matched compound. A DILIrank row is cited as evidence for a hepatic
`burdens` relation **only** when its class is `vMost-DILI-concern` or `vLess-DILI-concern`.
A `vNo-DILI-concern` or `Ambiguous-DILI-concern` row is recorded as consulted, with its
real classification, and is not used to support a claim it does not support.

## PubMed bibliographic citations

- **Licence recorded as:** `own-curation`
- **URL:** <https://pubmed.ncbi.nlm.nih.gov/>
- **Evidence id namespace:** `pubmed:<PMID>`

A PMID identifies literature consulted while hand-curating an entry — chiefly the peptide
and research-chemical tier, where no FDA label exists. **No abstract or article text is
reproduced.** The catalog value is original curation; the PMID exists so a reader can go
and check the same literature. The licence is recorded as `own-curation` rather than as any
publisher's licence precisely because none of the publisher's material is being carried.

Every PMID in this repository was resolved against the live NCBI E-utilities API and
verified to exist. None was written from memory.

## Sources deliberately NOT used

These are recorded so that a future contributor does not "helpfully" reintroduce one.

| Source | Why not |
|---|---|
| **WHO ATC / DDD Index** | Licensed for non-commercial use only. Incompatible with a saleable catalog. Not used, not imported, not consulted for classification. |
| **DrugBank** | Closed and commercially licensed. Not used. |
| **ChEMBL** | Licensing for this use is unresolved. Not used pending a decision. |
| **DrugCentral** | Licensing for this use is unresolved. Not used pending a decision. |
| **SNOMED CT** | Excluded by the product specification (`human-system` SPEC §1.3). Not used anywhere, and no file embedding it may be imported. |
| **LOINC** | Not retrieved. LOINC requires a code to travel with one of four approved display names, reproduced verbatim. This catalog therefore publishes **no** LOINC codes; the app owns that binding. See `data/marker-keys.json`. |
| **bodyhackguide.co** | Used **only** as a coverage checklist — a list of which compounds this audience expects to see. No text, grouping, number, ordering or phrasing was taken from it. Every value in this repository comes from a source named above or from original curation, and every row records which. |
